# پروژه اندرویدی مدیریت هزینه‌ها

این پروژه نسخه گرافیکی اولیه برنامه ثبت هزینه است. اطلاعات در پایگاه داده SQLite ذخیره می‌شوند.

## ساخت APK
این پروژه شامل GitHub Actions workflow است که با اجرای آن در GitHub، فایل APK ساخته و به‌صورت Artifact قابل دانلود ارائه می‌شود.

1. فایل ZIP را استخراج کنید.
2. فایل‌ها را در یک repository جدید در GitHub آپلود کنید.
3. در بخش Actions، workflow با نام `Build Android APK` را اجرا کنید (یا با push روی شاخه main خودکار اجرا می‌شود).
4. پس از اتمام موفق، از اجرای workflow بخش Artifacts، فایل `expense-manager-apk` را دانلود کنید.
5. ZIP مربوط به Artifact را روی گوشی باز کنید و فایل APK را نصب کنید.

ساخت APK ممکن است زمان‌بر باشد و در اولین build ابزارهای Android SDK/NDK دانلود می‌شوند.
این نسخه آزمایشی است؛ رابط فارسی بسته به فونت و دستگاه ممکن است به بهبود راست‌چین/اتصال حروف نیاز داشته باشد.
